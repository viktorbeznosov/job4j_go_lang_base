2. Прямое преобразование большого int64 в int16 не проверяет диапазон
   Потому что в Go приведение типов (T(x)) — это не проверяемая операция, а низкоуровневое переинтерпретирование битов. Спецификация языка прямо говорит: при преобразовании между целочисленными типами значение усекается до разрядности целевого типа, и никакой ошибки не возникает.
